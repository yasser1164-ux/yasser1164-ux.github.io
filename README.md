# yasser1164-ux.github.io

Personal portfolio for **Yasir Alghamdi** — Project Lead, capital projects
and technical assurance.

Live at <https://yasser1164-ux.github.io/>

Plain HTML/CSS/JS, no build step.

```
index.html    the whole page — hero, about, experience, expertise,
              the four engineering drawing sheets, credentials, contact
styles.css    all styling, including the light/dark theme tokens
script.js     nav, scroll reveal, counters, and the drawing interactions
img/          portrait and any future imagery
```

## Editing

Change a file and commit to `main`. GitHub Pages publishes this repo
automatically because it is named `<username>.github.io` — no workflow
needed. The site is live about a minute after each push.

## Themes

The page follows the visitor's system light/dark setting by default. The
sun/moon control in the nav overrides it and the choice is remembered.
